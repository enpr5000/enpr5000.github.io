개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-27

이 방침은 YouTube 채널 "5PM 이슈 브리핑"(@issue5pm)과 그 운영자가 사용하는 업로드 도구 "5PM Issue Briefing Uploader"(이하 "도구")에 적용됩니다.

This policy applies to the YouTube channel "5PM Issue Briefing" (@issue5pm) and the uploader tool "5PM Issue Briefing Uploader" (the "Tool") used by its operator.

1. YouTube API 서비스 사용 / Use of YouTube API Services

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 개인정보 처리에 관해서는 Google 개인정보처리방침이 적용됩니다.

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Google's handling of personal data is governed by the Google Privacy Policy.

2. 접근하는 정보 / Information accessed

도구는 채널 운영자 본인이 Google 계정으로 허용한 범위 안에서만 다음 정보에 접근합니다.

  • 운영자 본인 YouTube 채널의 기본 정보(채널 이름, 채널 ID): 올바른 채널에 업로드되는지 확인하는 용도
  • 운영자 본인 채널에 동영상, 썸네일, 자막을 업로드하고 그 메타데이터(제목, 설명, 태그, 공개 상태)를 설정하는 권한

The Tool only accesses, within the scope the channel operator granted with their own Google account: (a) basic information about the operator's own YouTube channel (channel name and ID), to confirm uploads go to the correct channel; and (b) permission to upload videos, thumbnails and captions to the operator's own channel and set their metadata (title, description, tags, privacy status).

도구는 다른 YouTube 사용자나 시청자의 정보를 수집, 조회, 저장하지 않습니다.

The Tool does not collect, read or store information about any other YouTube user or viewer.

3. 사용 목적 / How information is used

접근한 정보는 운영자가 만든 뉴스 요약 영상을 운영자 본인의 채널에 업로드하는 데에만 사용합니다. 광고, 프로파일링, 판매, 제3자 제공 등 다른 목적으로는 사용하지 않습니다.

Information is used solely to upload the operator's own news summary videos to the operator's own channel. It is never used for advertising, profiling, sale, or sharing with third parties.

4. 저장과 보호 / Storage and security

Google이 발급한 인증 토큰은 운영자의 개인 PC에만 저장되며, 외부 서버로 전송되거나 다른 사람과 공유되지 않습니다. 도구는 별도의 서버나 데이터베이스를 운영하지 않습니다.

The OAuth token issued by Google is stored only on the operator's personal computer. It is never transmitted to any other server or shared with anyone. The Tool does not operate any server or database.

5. 공유 / Sharing

접근한 정보를 제3자와 공유하거나 판매하지 않습니다. 업로드한 영상은 YouTube에 게시되며, YouTube 및 Google 정책에 따라 처리됩니다.

No information is shared with or sold to third parties. Uploaded videos are published on YouTube and handled under YouTube's and Google's policies.

6. 보관 기간과 삭제, 권한 해제 / Retention, deletion and revoking access

인증 토큰은 운영자가 도구를 사용하는 동안만 보관하며, 사용을 중단하면 PC에서 삭제합니다. 언제든지 Google 계정 보안 설정 페이지에서 도구의 접근 권한을 해제할 수 있으며, 해제하면 도구는 더 이상 채널에 접근할 수 없습니다.

The token is kept only while the operator uses the Tool and is deleted from the computer when use stops. Access can be revoked at any time via the Google security settings page; once revoked, the Tool can no longer access the channel.

7. 시청자 정보 / Viewers

이 웹사이트와 도구는 시청자나 방문자의 개인정보를 수집하지 않으며, 쿠키나 분석 도구를 사용하지 않습니다. YouTube에서 영상을 시청할 때의 정보 처리는 Google 개인정보처리방침을 따릅니다.

This website and the Tool do not collect personal information about viewers or visitors and use no cookies or analytics. Data processing when watching videos on YouTube is governed by the Google Privacy Policy.

8. 변경 / Changes

이 방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.

Any changes to this policy will be posted on this page with a new effective date.
